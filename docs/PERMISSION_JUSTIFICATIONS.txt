PERMISSION JUSTIFICATIONS: Omni AI

Source of truth for the Chrome Web Store "Privacy practices" permission justification fields. Paste the matching block below into the Chrome Web Store Developer Dashboard, Privacy tab, Permission justification. The dashboard asks for a justification for every one of `manifest.json`'s permissions and its host permission field: `storage`, `activeTab`, `contextMenus`, `sidePanel`, and the host permissions `https://*/*` and `http://*/*`. Keep this file in sync with manifest.json permissions whenever they change.

Verified against source: manifest.json, background/service-worker.js, content/content.js, sidepanel/sidepanel.html, sidepanel/sidepanel.js.

====================================================================

storage
=======

Justification to paste (616 characters, under the 1000 character store limit):

The storage permission lets Omni AI save the user's own preferences entirely on-device. chrome.storage.sync holds the primary/secondary translation language and the light/dark theme, so they follow the user's signed-in Chrome profile across devices. chrome.storage.local holds the AI provider API key(s) the user enters, the selected model/preset, Custom Gateway settings, and local usage statistics (actions run, words processed). Nothing here is sent to any Omni AI server: none exists. It is read only to restore the user's own settings and to send their configured API key directly to the AI provider they chose.

====================================================================

activeTab
=========

Justification to paste (583 characters, under the 1000 character store limit):

The activeTab permission lets the extension read the content and selection of the tab the user is actively working in, only after they explicitly interact with the extension: clicking the toolbar icon, selecting text that triggers the floating button, or invoking a keyboard shortcut or a right-click menu item. That access runs the requested AI action (grammar, rephrase, summarize, translate, explain, emoji, etc.) on the page's text and inserts the result back in place with the Replace action. It is never granted or used in the background without that explicit user interaction.

====================================================================

contextMenus
============

Justification to paste (541 characters, under the 1000 character store limit):

The contextMenus permission adds right-click menu items (Rephrase, Fix Grammar, Translate, Summarize, Explain, Add Emoji, and Ask Omni AI) so the user can trigger an AI action on selected text, or on the page itself, directly from the browser's native context menu, without first opening the extension's own UI. Selecting an item sends the relevant text to the AI provider the user configured in Settings, using their own API key, and shows the result back on the page. No text is read or sent unless the user explicitly chooses a menu item.

====================================================================

sidePanel
=========

Justification to paste (991 characters, under the 1000 character store limit):

The sidePanel permission opens Omni AI's browser side panel, a docked panel that stays attached to the browser window. It hosts the extension's "Page Tools": one-click AI actions (Summarize, Smart Translate, Explain) that run on the whole page the user is reading.

Clicking the toolbar icon opens the panel via chrome.sidePanel.setPanelBehavior({ openPanelOnActionClick: true }). The buttons read the current page's text and send it to the AI provider the user configured in Settings to produce a summary, translation, or explanation.

A docked panel is used instead of a popup because a popup closes when it loses focus at the moment the user scrolls back into a long article. The side panel stays open while the user reads, so the result remains visible.

Data handling: the panel reads page text only when the user invokes a Page Tool, sent directly to the user's chosen provider via their own API key, never stored or sent to any Omni AI backend, and used only for the requested result.

====================================================================

Host permission (https://*/* and http://*/*)
=============================================

Justification to paste (620 characters, under the 1000 character store limit):

The host permissions (https://*/* and http://*/*) let Omni AI's content script run on every page automatically, since text selection can happen on any website and the floating button and quick-action menu must be ready the moment the user selects text, without requiring a click first. They also let the background service worker send the user's request directly to whichever AI provider endpoint the user has configured in Settings, Google Gemini, OpenAI, Groq, Anthropic Claude, or an arbitrary Custom Gateway URL the user supplies, since that endpoint cannot be known in advance or limited to a fixed list of domains.

====================================================================

Declaration for the "Privacy practices" (data collection) questions
===================================================================

When Google asks whether the extension collects or transmits user data, answer truthfully per the code:

- Yes: the extension sends the content of the active page (for Page Tools) and the user's selected text (for Selection Menu actions) to the AI provider the user chooses (Google Gemini, OpenAI, Groq, Anthropic Claude, or a Custom Gateway), using the user's own API key.
- No: it does NOT send that data to an Omni AI backend/server (none exists), does NOT store it, does NOT use it for advertising, and does NOT sell or share it.
- This is user-initiated data sent to a third-party provider of the user's choosing, and is limited strictly to producing the requested AI result (summarize, translate, explain, rephrase, grammar, tone, emoji, etc.).

Note on the "third party" wording: declaring that data is sent to a third party does NOT contradict the "no Omni AI backend" claim: the third party here is the AI provider the user configured, while no Omni AI backend exists. Describe it exactly as above.
